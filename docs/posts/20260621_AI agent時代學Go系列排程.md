# AI agent 時代學 Go 系列排程

## 系列定位

以 WebRTC Phase 4 的 Go 信令服務為教材，記錄我如何把 AI agent 當成程式教練，從可執行的真實程式碼出發，透過一問一答、執行驗證、log 判讀與誤解修正，逐步學會一門新語言。

## 文章順序

1. 我怎麼把 AI agent 當成 Go 程式教練，而不是程式碼產生器
2. 先讀懂專案，再讀懂語法：我如何從 WebRTC 專案開始學 Go
3. goroutine、channel、Hub：第一次看懂 Go 併發到底在做什麼
4. WebSocket 生命週期：readPump、writePump 與斷線清理怎麼串起來
5. signaling 事件流：join、signal、leave 怎麼在 Go server 裡流動
6. 最小化除錯：我怎麼靠 log 讀懂 Go 服務的行為
7. 在 AI agent 時代，怎麼更主動地學一門新程式語言

## 每篇固定骨架

1. 這篇要解決什麼問題
2. 我一開始哪裡不懂
3. AI agent 先帶我看哪個檔案或事件流
4. 我怎麼追問
5. 第一版理解錯在哪裡
6. 修正後我真正懂了什麼
7. 回到專案或 log 驗證一次
8. 如果你也想這樣學，可以怎麼問 AI

## 寫作原則

- 不寫成教科書式 Go 全面課程
- 保留真實互動片段，但不直接貼完整逐字稿
- 每篇都要同時交代技術理解與學習方法
- 每篇都要能對照回實際專案與執行結果
